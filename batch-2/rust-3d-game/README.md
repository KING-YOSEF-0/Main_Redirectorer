# Rust 3D Cyber World Game

## Overview
A large-scale, 3D animated browser game powered by Rust + WebAssembly and Three.js. This game demonstrates high-performance gaming in the browser with advanced 3D rendering and physics simulation.

## Features
- **Rust WASM Core**: Performance-critical game engine compiled to WebAssembly
- **Three.js Rendering**: Sophisticated 3D graphics and animations
- **Large-scale Object Grid**: Procedural generation of 3D objects (cubes, spheres, pyramids)
- **Real-time Physics**: Interactive player movement and object dynamics
- **Responsive Design**: Works across devices (desktop, tablets, mobile)

## Technical Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **3D Engine**: Three.js
- **Game Engine**: Rust (compiled to WebAssembly)
- **Architecture**: Modular design with clear separation of concerns

## Game Mechanics
- Player movement and interaction
- 3D object generation and animation
- Procedural physics simulation
- Score tracking and progression system

## Development
This game serves as a prototype for large-scale 3D gaming in the browser, showcasing the capabilities of Rust WASM for performance-critical game components while maintaining smooth interactive experiences with JavaScript.

## Files
- `src/lib.rs`: Rust WASM game engine
- `index.html`: Game entry point
- `style.css`: Styling and UI components
- `script.js`: Three.js integration and game loop
